# 🔨 Blind Auction - Python Project

## Project Description
Blind Auction is a command-line Python program where multiple bidders can place their bids privately. The program compares all bids and announces the highest bidder as the winner.

## Features
- Multiple bidders can participate.
- Each bidder enters their name and bid amount.
- Bids are stored in a Python dictionary.
- Automatically identifies the highest bidder.
- Announces the auction winner.

## Technologies Used
- Python 3

## Python Concepts Used
- Functions
- Dictionaries
- While Loops
- For Loops
- If-Else Statements
- User Input
